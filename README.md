# Splunk SOC Level 1 Investigation Lab

## Project Overview
This project documents my hands-on practice using Splunk Enterprise in an Ubuntu virtual machine to develop practical Security Operations Centre (SOC) Level 1 analyst skills.

## Lab Environment
- Operating System: Ubuntu Linux
- Virtualisation: Oracle VirtualBox
- SIEM: Splunk Enterprise
- Splunk Web Interface: `http://127.0.0.1:8000`

## Objectives
- Start and verify Splunk services.
- Search and analyse log data using Splunk Processing Language (SPL).
- Investigate authentication-related events.
- Identify potentially suspicious login activity.
- Document findings and prepare a basic incident report.

## Work Completed
- Confirmed the Splunk executable exists at `/opt/splunk/bin/splunk`.
- Checked the ownership and permissions of the Splunk installation directory.
- Started Splunk under its dedicated `splunk` user.
- Confirmed that the Splunk Web interface became available.
